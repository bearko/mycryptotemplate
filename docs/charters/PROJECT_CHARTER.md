# プロジェクト憲章 — MyCryptoSurvivor

- **プロジェクト名**: MyCryptoSurvivor
- **タグライン**: ヒーローを操作しながら敵を倒し、 時間いっぱい生き残る
- **ジャンル**: ローグライク・ロールプレイング / オートシューティング弾幕 (= Vampire Survivors 系)
- **作成日**: 2026-05-09
- **テンプレート起点**: bearko/mycryptotemplate

## 1. プロジェクトの目的

MyCryptoSurvivor は、 **MCH (My Crypto Heroes) の世界観のヒーロー / エネミーを使って Vampire Survivors 風のオートシューティング弾幕を遊ぶ** ブラウザゲームである。

プレイヤーは MCH の Common ヒーロー 1 体を選択し、 制限時間 (= 5 分) のステージで自動攻撃しながら敵をかわしつつ生存することを目指す。 倒したエネミーから経験値 (CE アイコン) と回復 (HP アイコン) がドロップし、 レベルアップ毎に **エクステンション (= 武器・装備のシリーズ)** をランダム 3 択から選んで強化していく。 同シリーズのエクステンションを取り続ければレアリティが Common → Uncommon → Rare → Epic → Legendary と昇格し、 最大 Legendary に到達した状態でステージクリアを狙う。

MCT / MCF と同じく **「ヒーローと CDN アセットの再利用」 + 「短時間で 1 試合が完結する遊び心地」** を両立させ、 既存ファンには馴染みのキャラを、 新規プレイヤーには手軽なローグライト体験を提供する。

## 2. スコープ

### In Scope (= MVP で作るもの)

1. **タイトル → ヒーロー選択 → ステージ選択 → ゲームプレイ → リザルト** までの 1 ループ
2. **1 ステージ**: プレイ時間 5 分、 MCH エネミー 3 種、 ドロップ 2 種 (CE / HP)
3. **Common ヒーロー 10 体**: 各ヒーローに固有の初期エクステンション (例: コナン・ドイル → ステッキシリーズ、 張遼 → アックスシリーズ)
4. **エクステンション 10 シリーズ**: 各シリーズは Common → Uncommon → Rare → Epic → Legendary の 5 段階。 レベルアップ時のドロップで同シリーズを取得すると昇格
5. **i18n (ja / en)** および **PC + Mobile 両対応**
6. **時間進行制御**: ステージ中の 5 分カウント。 メニュー / モーダル中は `pauseFlags` で停止

### Out of Scope (= MVP では作らない)

- ランキング (GAS + Spreadsheet) — 将来の SPEC で追加
- セーブ / ロード — 1 試合完結なので不要
- 月次イベント (年単位ループ) — Vampire Survivors 系には不要
- 並列スロット (= MCF の並列クラフト的な仕組み)
- Rare 以上のヒーロー (= MVP は Common 10 体のみ)
- 複数ステージ / ボス戦 / メタプログレッション — 後の SPEC で検討

## 3. 成功基準

- [ ] 1 試合 5 分のループが Console エラーなしで遊べる
- [ ] ヒーロー 10 体 × エクステンション 10 シリーズが切替表示される
- [ ] レベルアップ時の 3 択モーダルで `pauseFlags` が正しく機能する (= 裏で時間が止まる)
- [ ] Mobile 375×667 / PC 1280×800 でレイアウト崩れがない
- [ ] ja / en 切替で全 UI 文字列が翻訳される
- [ ] ステージ中のフレームレート 30fps 以上 (= モバイル含む)

## 4. 制約

| 項目 | 内容 |
|---|---|
| 技術 | プレーン ES Modules + バニラ JS。 TypeScript / バンドラ / フレームワーク **なし** |
| ホスティング | 静的 (Vercel 想定) — `build:` ステップなし |
| 多言語 | ja / en の 2 言語 |
| ターゲット | PC ブラウザ (1280×800 〜) + モバイル (= iOS Safari / Chrome Android、 375×667 〜) |
| アセット | `bearko/MyCryptoSurvivor-assets` 別リポジトリから raw URL 参照 |
| localStorage prefix | `mcs.*` (= MyCryptoTemplate / MCT / MCF と衝突しない) |
| ビジュアルトーン | ピクセル (= Vampire Survivors 系のドット絵) |

## 5. 主要なペルソナ

### Persona A: MCH ファン (主)
- **背景**: My Crypto Heroes を遊んでいた / 知っている
- **動機**: 推しヒーローを別の遊びで動かしたい、 短時間で MCH 世界観に触れたい
- **行動**: タイトル → 推しヒーロー選択 → 5 分プレイ → リトライ
- **満足条件**: ヒーローのアセットがちゃんと CDN から出ている / 操作が直感的

### Persona B: ローグライト初心者
- **背景**: Vampire Survivors / 20MTD 等の経験あり、 MCH は未経験
- **動機**: ブラウザですぐ遊べる短時間ローグライト
- **行動**: タイトル → 適当なヒーローでプレイ → エクステンション昇格を確認
- **満足条件**: 進化のサプライズ感 / 5 分でまとまる時間設計
